# 자동 재시작 트레이 (AutoRestartTray)

Windows용 포터블 PC 자동 재시작 프로그램입니다.

## 기능
- **24시간 내 시간 설정으로 PC 자동 재시작**
  - `매일 지정 시각` 모드: 예) 매일 새벽 04:00 재시작
    → **한 번 설정하면 매일·재부팅 후에도 자동 반복** (다시 설정 불필요)
  - `카운트다운` 모드: 예) 지금부터 3시간 후 1회 재시작
- **✕(닫기)를 눌러도 종료되지 않고 트레이로 최소화**되어 계속 동작
- **부팅 시 자동 실행**되어 트레이에 상주 (창 없이 트레이로만 뜸)
- 재시작 전 **경고(유예) 시간** 동안 `재시작 취소` 가능
- **경고창 없이 조용히 즉시 재시작** 옵션 (Windows 재시작 팝업/알림 없이 바로 재부팅)
- 관리자 권한 불필요 · 설정은 EXE 옆 `config.json` 에 저장(포터블)

---

## 1. 포터블 EXE 만들기 (최초 1회, Windows에서)

> EXE 빌드는 **Windows + Python**이 있는 PC에서 한 번만 하면 됩니다.
> 만들어진 `AutoRestartTray.exe` 는 Python 없는 PC에서도 그냥 실행됩니다.

1. [python.org](https://www.python.org/downloads/) 에서 Python 설치
   (설치 시 **Add Python to PATH** 체크)
2. 이 폴더에서 **`build.bat` 더블클릭**
3. 끝나면 `dist\AutoRestartTray.exe` 생성 → 이 파일 하나만 원하는 폴더(예: `C:\Tools\`)로 복사

## 2. 사용법
1. `AutoRestartTray.exe` 실행
2. 재시작 시점(매일 지정 시각 / 카운트다운) 선택 후 값 입력
3. **활성화** 체크 → **적용** 클릭
4. ✕ 를 누르면 트레이로 들어갑니다. 트레이 아이콘 우클릭으로 메뉴(열기/활성화/재시작 취소/종료)

## 3. 부팅 자동 실행
- `부팅 시 자동 실행` 체크 후 `적용` 하면 다음 부팅부터 자동으로 트레이에 상주합니다.
- 동작 원리: 레지스트리 `HKCU\...\CurrentVersion\Run` 에 `--tray` 옵션으로 등록 (관리자 권한 불필요)
- 해제하려면 체크 해제 후 `적용`.

---

## 빌드 없이 바로 테스트
Python이 있다면 `run.bat` 더블클릭으로 즉시 실행됩니다.

## 참고
- 재시작 명령은 Windows 내장 `shutdown /r /t <초>` 를 사용합니다.
  경고 시간 동안 `재시작 취소`(= `shutdown /a`)가 가능합니다.
- 일부 백신이 PyInstaller로 만든 EXE를 오탐할 수 있습니다.
  필요하면 예외 등록하거나, `build.bat` 의 `--onefile` 을 `--onedir` 로 바꿔 폴더형으로 빌드하세요.

| `run.bat` | 빌드 없이 바로 실행(테스트) |
